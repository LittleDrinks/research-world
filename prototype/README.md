# Prototype
一次性原型，用于回答设计问题。当前主目录：
- `dpskv4vi/` — Research World 前端重构视觉原型集（12 套独立 HTML 预览 + React 交互原型）
- `dpskv4p/` — Research World 前端挑战 24 套（完整系统/局部组件/125 命题，独立 HTML 可双击预览，截图与验证脚本齐备）
- `ascii-art-effects/` — Research World ASCII 字符艺术效果画廊（8 套纯文本效果，可直接打开 index.html）
- `ascii-glass-light/` — Research World 浅色 ASCII 玻璃效果集（桌面与移动端可直接打开）
- `kort-ai-ascii/` — Kort AI 着陆页字符动效复刻（整站零图片：噪声点阵 Hero、SDF 字符图像、字符地球、二进制圆环，打开 index.html）
- `kimi/` — Research World 完整界面选型原型（10 套源码与 1600x1000 筛选截图）
