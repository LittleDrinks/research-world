# dpskv4vi — Research World 前端重构视觉原型集

黑蓝深海 / 玻璃 UI / ASCII 原子像素 / 未来主义开发者网站方向的 12 套独立视觉参考。
每套原型位于独立文件夹，可直接打开 `index.html` 预览。

| # | 文件夹 | 视觉概念 | 核心使用逻辑 |
|---|--------|----------|--------------|
| 01 | abyss-glass | 深海底玻璃面板 | 地图优先 + 右侧审查检查器 |
| 02 | ascii-terminal | 终端 / 扫描线 / ASCII 原子 | 命令与轨迹优先 |
| 03 | mission-control | 任务控制台 / 雷达遥测 | 指标与队列优先 |
| 04 | blueprint | 工程蓝图 / 网格标注 | 审计与规格优先 |
| 05 | editorial-future | 未来杂志 / 大字号编辑排版 | 叙事与项目入口优先 |
| 06 | submarine-hud | 潜艇 HUD / 声呐 / 仪表 | 操作与裁决优先 |
| 07 | neural-field | 神经场 / 粒子光点 | 沉浸式图谱探索 |
| 08 | quantum-console | 开发者 IDE / 量子控制台 | 编写工作流优先 |
| 09 | agent-deck | 多智能体驾驶舱 | 事件流与 agent 调度优先 |
| 10 | minimal-abyss | 极简深渊 / 留白 | 单点专注 |
| 11 | orbital-timeline | 轨道 / 环形谱系 / 时间轴 | 谱系与时间追溯 |
| 12 | pixel-lab | 像素实验室 / 8-bit 玻璃 | 游戏化研究推进 |

对应 React 交互原型：`prototype/dpskv4vi/react/DeepSeaDesignPrototype.jsx`
访问：可在 React 工程中挂载为 `/prototype/deep-sea?variant=A` 到 `L`，用底部浮条或 ← / → 切换。
