## 推导

1. 研究世界的页面不该按“项目/地图/对话/活动”四个页切，而应按**研究者此刻要回答的问题**切：有什么新东西、哪里失败、下一步做什么、错误影响了谁、证据可不可复现。
2. 图谱主屏的瓶颈不是布局，是**阅读入口**：全局图不可读，单节点上下文平铺不可读。所以 v02 引入图例/图层/目录/比例尺，v12 引入五层解剖。
3. waiting_human 与 ghost 是两类被现有 UI 埋没的强信号：一个决定吞吐，一个决定探索质量。v11、v13 把它们各自升级为 first-class surface。
4. 大规模（125 题、5000 节点）不是“以后的事”：v01/v10/v18 证明当前数据模型在浏览器内可渲染、可筛选、可计时。
5. 深度演示题的人工返回数据（JPL/湿实验/手表）需要在 UI 里有闭环位置：v07/v08/v23 各占一个命题页，v21/v22 是文献与材料证据链。
