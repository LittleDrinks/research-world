# 审核与执行管线

## 入图前审核，驳回内容隔离
行动与结果通过独立审核后才成为默认可检索内容；被驳回内容保留为隔离记录，只在后续入图审核时用于相似性匹配；执行 agent 只收到最小阻断理由，完整内容仅向审核 agent 和人工披露。[HEP](https://arxiv.org/abs/2607.09195) 不让未经 verdict 的假设派生后代，[无外部反馈的自纠不构成独立验证](https://arxiv.org/abs/2310.01798)，[可验证溯源](https://arxiv.org/abs/2607.25637)要求主张、证据、审核者在同一条记录上。

## 规划产生行动，行动触发执行
规划 agent 一次只提交一个候选行动，系统不因前沿为空而自行无界规划；行动通过独立审核后原子且幂等地创建一次执行；规划与执行使用不同会话。[计划遵循可在离散步骤上测量](https://arxiv.org/abs/2604.12147)，[在线监控与纠偏](https://arxiv.org/abs/2608.06701)以步骤为边界，[自主实验系统](https://www.nature.com/articles/s41586-023-06734-w)在执行、观察和下一步选择间建立可观测反馈。

## 分离盲创与反思
盲创会话不读已有路线与隔离记录，每会话只提交一个候选；需要披露重合点或沿已有工作修改时新建反思会话，只提供相关图谱切片与最小审核意见；任何历史披露即结束盲创状态。研究 agent 的候选会[向既有语义邻域收缩](https://arxiv.org/abs/2605.27905)，[采样机制不能伪装独立探索](https://arxiv.org/abs/2510.01171)，新颖性需[分别比较问题、方法和主张](https://arxiv.org/abs/2602.06054)。

## 分离机制审核与执行审核
机制重合审核与执行有效性审核分开，不由一个模型同时判新颖性、任务适配、泄漏、预算与可证伪性；机制审核保留带来源的 same/different/uncertain 局部判断，冲突进入人工队列。[ARIS](https://arxiv.org/abs/2605.03042) 分阶段审计，[多维 verdict 混判会丢判定依据](https://arxiv.org/abs/2608.06422)。

## 分离执行、结果审核与评分
执行 agent 只读行动、训练数据、工具与评价接口；隐藏目标由独立评分进程持有；格式验证不等于入图，结果审核检查输入边界、代码、环境、日志与产物哈希并以规范化内容哈希复跑。[Matbench](https://doi.org/10.1038/s41524-020-00406-3) 固定评测边界，[held-out transfer](https://arxiv.org/abs/2607.17100) 外层独立评价，[审计记录须同时证明输入边界与产物链](https://arxiv.org/abs/2608.05235)。

## 按运行能力调度
注册 agent 时记录模型接口、工具、传输协议、上下文预算与执行资源，队列只调度满足能力的实现；SDK 名称或兼容 URL 不算能力证明，协议失败后空证据不是有效结果。[LongMemEval-V2](https://arxiv.org/abs/2605.12493) 把 memory 视为运行时接口，[harness 可靠性取决于模型外的工具与状态边界](https://arxiv.org/abs/2604.25850)，[A2A 能力声明](https://a2a-protocol.org/latest/specification/)只用于发现候选。

## 人机共用节点提交接口
人与 agent 经同一命令接口创建待审节点，共用规范化、系统身份、结构校验、审核门与事件记录；UI/CLI/SDK 只是适配器，人工提交不跳过审核。[PROV](https://www.w3.org/TR/prov-dm/) 把 actor 与实体分开归因，[可执行溯源](https://arxiv.org/abs/2607.25637)要求提交者与审核者同录，单一写入门落实[最小权限](https://csrc.nist.gov/pubs/sp/800/53/r5/upd1/final)。
