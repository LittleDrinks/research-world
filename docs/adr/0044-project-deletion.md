# 删除项目
项目列表提供独立删除按钮；确认框显示项目名称和不可恢复的数据范围，取消不产生写入。删除不等于图谱节点撤销。
Control 串行处理同一 Project 的会话创建、消息提交、标题启动和删除。Runtime 在注册锁内检查该 Project 的所有 Run（含子 Run 与标题提取）；仍在执行或清理的任务阻止删除，返回409，用户先停止任务后重试。
Runtime 清理自己拥有的 Run、Turn、消息索引、事件与内存引用；Control 随后清理工作目录、Artifact、会话、图谱与 Project。删除不接收任意文件路径，不修改全局 Agent 配置、其他 Project 或仓库内的原始研究材料。
跨服务失败不显示成功；Project 最后删除，未完成操作可重试。项目不存在时DELETE返回204。浏览器删除当前项目后移除失效选择并刷新项目列表；最后一个项目删除后仍可新建项目。
