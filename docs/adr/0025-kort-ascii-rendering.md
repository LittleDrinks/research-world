# Kort 字符雕塑：统一 3D 点云投影
卡片、地球、特性图标与 Why 主视觉统一为 3D 点云，经透视投影、字符栅格 z-buffer、深度着色与垂直残影生成二进制雕塑。三张市场卡分别固定为厚圆环、水平粗箭头、折叠长带，只做小角度摆动。地球以大陆轮廓控制点密度。六个特性图依次为五叶旋涡球、层叠环、空心鼓形圆柱、半环头盔、人像胸像、DNA。Why 主视觉在四叶体、苹果状团块、中心球加外环、实心球间 morph，四叶体与苹果状态带卫星小球。近景用深紫实色，远景用低透明浅紫；轮廓内部保持细密字符，禁止退回二维 SDF 填充。Hero 使用稀疏金融字形马赛克。单一 `requestAnimationFrame` 调度，可见区域渲染；无外部依赖与图片资源。
