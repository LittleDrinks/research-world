# Kort 精确复刻：参考动效字符量化
Kort 是未公开上线的设计概念；公开材料只有完整线框稿、分段动效和录屏，没有可抓取站点或工程。
页面按录屏固定为三段：Hero 的 `x/o` 反相字符场与横向市场画廊；地球预测面板与六格字符画廊；Why 区 10–30 秒的连续形变和三项统计。市场画廊至少六项，禁止收缩为三张卡。
图形沿用原作者的素材驱动流程：矢量或三维运动先形成亮度场，再量化为字符。参考视频离线裁剪、降采样并编码为 4-bit 字符密度帧；浏览器只读取密度并实时绘制 `x/o` 或 `0/1`，运行时不加载图片或视频。
HTML 负责文字、边框、画廊和响应式布局。Canvas 只负责字符图形。通用 3D 点云、SDF 猜形和噪声替代品全部删除。
