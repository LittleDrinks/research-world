# 历史报告中的研究方向
一份报告不是一个 Direction。历史报告与版本保存为不可变 Artifact；报告中提出的独立解释、机制或路线分别形成 Direction，各自依赖 Question 并直接关联原报告 Artifact，不从报告级引用列表推断方向的支持或反驳关系。
每题从当前交付报告提取方向：存在深度案例 final 时使用该版本，否则使用全量候选报告。旧版本仍可查看，旧版本的方向不重复加入当前图。
固定语料使用经过核对的原文片段清单：记录报告路径、SHA-256、方向标题及字符区间，区间允许不连续，以保存与该方向分开陈述的证据。导入核验哈希、范围与数量；缺失或漂移直接失败，不用整份报告充当方向。
Direction 保留原文、来源位置和未核验标记；报告级交付状态留在原报告 Artifact，不下放为方向的科学结论。修正已有导入只调整本次导入生成的表示，保留 Project ID、原文 Artifact、轨迹与用户新增记录。
