Research World · Design

一张会生长的研究图谱，
每个决策都有文献支撑

人机协作的科研系统：人只与助理对话，agent 的工作在图谱上可见。本页讲清楚它是怎么设计的、为什么这么设计——正文上标数字即支撑文献。

Overview

闭环：命题 → 实验 → 反思 → 新命题

auto 开：review 通过即自动进入下一轮迭代；同一谱系连续 2 次驳回 → 熔断、升级人工[14]。
auto 关：direction 启动与每步 plan 执行均需人确认。
失败经验两条复用路径：reflect 把失败反思成新 direction 候选，挂在父 direction 下、同一谱系（谱系连续驳回 2 次触发熔断）；或从头 brainstorm 开新谱系，但向生成侧渐进披露最小阻断理由，避免重复踩坑[23]。
01 · Graph Model

图谱：固定四类节点，边带极性

调研了 SWAN[2]、Micropublications[1]、Nanopublication[3]、Discourse Graphs[5]、HEP[7]、Co-Scientist[20]、EvoScientist[23]、SEPIO[4] 等十几个本体与系统：没有一家全占我们要的特性，所以取各家之长组合——

系统claim 独立成类信念状态机极性边失败留图固定少类型
SWAN[2]✓—✓——
Micropublications[1]✓————
Nanopublication[3]✓ 唯一内容节点————
Discourse Graphs[5]✓————
HEP[7]✗ 并入 hypothesis✓——✓
Co-Scientist[20]✗✓——✓
EvoScientist[23]✗✓—✓ 失败方向记忆✓
SEPIO[4]————✓ 骨架+扩展点
本系统✗ 并入 direction✓✓✓ 幽灵车道✓ 四类

— = 该系统未强调。开放 taxonomy 的反面证据：学术话语本体十几个、互相重叠、采用率极低[6]。

result 不独立成节点：工作流传统（Kepler / AiiDA / Nanopublication）都把结果当实验的产出负载[3]。
状态机取 agent 工作流派：HEP[7]、Co-Scientist[20]、EvoScientist[23] 都把 claim 并入 hypothesis 加信念状态。
证据链是硬要求：ARIS 对失败案例的诊断——claim 证据不完整会被静默继承，产出"看似成立实则无据"的结论[9]。
边必须有极性：无极性的证据图退化为引用列表（IBIS、SWAN 的教训）[2]。
失败留图：线性叙事丢弃失败分支，后续研究被迫重复踩坑（Storytelling Tax）[8]；EvoScientist 消融实验：去掉失败方向记忆，novelty 显著下降[23]。
每条结论有 parent[12]；不够格的标 withheld finding 作可审记录保留[10]。
02 · Search Space

搜索空间：怎么判重，怎么不收敛

一篇覆盖 5 种框架 × 5 种模型 × 12 个学科的实证研究生成了 219,655 条 idea，结论是：prompt 里写"要新颖"、上更复杂的框架、换更大的模型，都不能拓广探索空间[22]；另一项受控实验证明多 agent 讨论反而导致过早收敛[31]。所以多样性必须是显式机制，不能靠嘱咐。

0.8 阈值：Si et al. 组织 100+ 名 NLP 研究者盲评数千条 LLM 生成的 idea，用 embedding 余弦 0.8 做去重；正是这批数据首次量化出"LLM 重复生成时多样性崩塌"[28]。
灰区交成对裁决：Chain-of-Ideas 在 50 个真实新课题上验证，LLM 两两比较与人评一致率 70.8%，比打分制更贴近人判[30]。
0.6 阈值：SciMON 用 0.6 触发"检索相近文献 → 反馈重写"，两轮重写后过半 idea 被人评判定更 novel[29]。
反例：AI Scientist v1 让 LLM 自由宣布 "novel / not novel"，独立复现证明它会把成熟概念误判为 novel——不让 LLM 自判[28]。
MMR 的实证：DivAlign 在 95 个真实 AI 研究课题的 benchmark 上对比——MMR 入池保留 99.9% 的质量分，同时把入选 idea 的最近邻相似度从 0.704 降到 0.608[27]。
生成侧叠加：Verbalized Sampling 让模型显式输出候选概率分布再采样，创意任务多样性提升 1.6–2.1×；但科研场景无实证，零成本叠加、收益不写进假设[24]。
废止 tournament / Elo：它解"相对排序"，不解"拓广"；219,655 条 idea 的实证里锦标赛演化同样不拓广探索空间[20][22]。
决策：embedding 初筛（数轴）→ LLM review 细筛（下一节）；升级组件——概念级相似图[25]、关系类型标注[26]、Component / Architectural novelty 区分[23]——后续可插入，不预埋。
03 · Review

评审：机械审计优先，人只在冲突时介入

claim 从哪来：claim 不是节点——review 启动时把 direction 的主张文本和 experiment 的结果文本拆成逐条原子断言作为审计单位；审计结果回写 direction 的状态机（supported / refuted）与极性边。
三阶段审计取自 ARIS 的声明审计协议；它的对抗评审要求评审者来自不同模型家族，抑制单一模型的系统性偏差[9]。
分维度分片：一次调用判多个维度会让部分判定失去证据 grounding；按维度拆开判，与专家的一致率显著提升（研究复现 / 法律 / 临床三域验证）[17]。
防漂移：客观机械检查与主观打分剥离，周期性用已知坏样本校准评审者[21]。
人是顶层反馈回路（Co-Scientist 的科学家反馈设计）[20]；熔断是"判建议分离"原则：确定性规则监控器命中才升级人，单实例成本 $0.08（LivePlan）[14]。
04 · Interface

界面：三视图，轨迹不做成审查界面

Bhambri et al. 逐条核验 agent 轨迹后发现：可读性没问题的 trace 里只有 28% 真的导向正确答案[16]；Kambhampati et al. 进一步指出中间 token 根本不是可信的推理窗口[15]。所以界面展示的全是结构化派生物，原始轨迹只作 drill-down 的最底层[18][11]。

失败是一等公民：TRACE 把失败归因到 context 组件 / 具体 step，操作准确率 96%[19]；21,120 条轨迹的实证表明 plan 偏离可度量、周期性提醒可缓解[13]。
页面取舍：审核、报告、智能体、队列不单独成页——审核并入图谱高亮，报告并入节点负载，队列降级为槽位指示。
05 · Honest Gaps

文献没回答的，自己趟

无 MCTS-on-ideas 先例idea 空间的树搜索没有成熟工作，"下一步选哪"先用规则 + 人。
rebuttal 无实证对 idea 质量的提升无定量研究，先作记录格式，不承诺收益。
人介入时机无定量研究熔断阈值（连续 2 次驳回）是默认值，需实测校准。
阈值跨学科漂移0.6 / 0.8 来自 NLP 语料，换学科需重新校准[28]。
Verbalized Sampling 未验证科研 idea 场景无实证，零成本叠加[24]。
深度重合无法自动判"换汤不换药"靠 review 与人兜底。
